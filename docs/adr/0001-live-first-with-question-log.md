# Live-first with question-log signals

NER's source-of-truth for team structure, leads, conventions, and repos is fast-moving and inconsistent across docs (the May-2026 grilling pass surfaced three competing org-chart framings in Confluence alone, and a Chief Software Engineer rename none of the static project docs reflected). Curated static reference content baked into Skill prompts would just create a fourth competing version that goes stale the moment officers turn over.

The Bundle's Skills carry **pointer-only** guidance — URLs to the Confluence space + GitHub org, plus rules for picking the right source — and answer every question by querying live via the Atlassian and GitHub Connectors. Specific facts (lead names, repo blurbs, version numbers, Slack channels) never get hard-coded; the Skill fetches them at query time.

Static content gets added selectively *later*, only when the question-log MCP shows live queries repeatedly failing on the same gap. No caching / TTL strategy in v1 either — until we observe usage, we can't pick a good one.

**Cite-or-decline (the teeth):** `ner-ask` must ground every NER-specific claim (repo purpose, architecture, ownership, who-connects-to-what, conventions) in a live query and cite it — or explicitly say it couldn't verify. It never states an NER-specific fact from model priors; general programming concepts may be answered freely. This is deliberately strict and may feel pedantic. It exists because the documented failure mode that motivated this whole project was a confident hallucinated cross-repo data flow (`Cerberus → Calypso → … → FinishLine`) produced by pattern-matching instead of querying. A future contributor will be tempted to loosen this to "answer well-known facts directly" — don't, until the question-log shows *where* strictness actually annoys people. Relax with evidence, not by assumption.

**Trade-offs accepted:** live queries are slower than static recall and break if Connectors fail; the Bundle is useless without working Atlassian/GitHub auth. In exchange we never serve stale facts (the single biggest failure mode for an onboarding agent in a club with annual officer turnover), and the maintenance burden stays close to zero. The question-log MCP, when it ships, becomes the empirical signal for what curation is worth the cost.

**Amended 2026-06-27:** Slack joined Atlassian and GitHub as a live source. `ner-escalation-router` resolves the current channel name from the Slack Connector — channels get renamed and archived and Confluence lags — and falls back to Confluence when Slack isn't connected. Slack is *optional* and off the critical path, so the trade-off above is unchanged: a missing Slack Connector only degrades channel lookup to the Confluence fallback, it doesn't make the Bundle useless.
